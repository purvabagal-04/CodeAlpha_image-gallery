🖼️ Image Gallery

A responsive and interactive Image Gallery created using HTML, CSS, and JavaScript.

The project includes image navigation, lightbox preview, hover effects, smooth transitions, responsive design, and category-based image filtering.

🚀 Features

📸 Responsive image gallery
🔍 Lightbox image preview
⬅️ Previous image button
➡️ Next image button
🎨 Hover effects
✨ Smooth transitions
📱 Mobile-friendly responsive design
🏷️ Image categories/filters
⌨️ Keyboard navigation
"←" Previous image
"→" Next image
"Esc" Close lightbox
🛠️ Technologies Used

HTML5 – Structure of the gallery
CSS3 – Styling, grid layout, hover effects and responsive design
JavaScript – Navigation, lightbox and category filtering
📁 Project Structure

Image-Gallery/ │ ├── index.html ├── style.css ├── script.js └── README.md

▶️ How to Run

Download or clone this repository.
Open the project folder in VS Code.
Open "index.html".
Right-click on "index.html".
Select Open with Live Server.
You can also simply open "index.html" directly in a web browser.

🖼️ Gallery Categories

The gallery currently contains three categories:

🌿 Nature
🏙️ City
🐶 Animals
Clicking a category displays only the images belonging to that category.

🔍 Lightbox

Click on any image to open it in a large lightbox view.

You can:

Click Next to see the next image.
Click Previous to see the previous image.
Click × to close the lightbox.
Use keyboard arrow keys for navigation.
Press "Esc" to close the lightbox.
📱 Responsive Design

The gallery automatically adjusts according to the screen size.

Desktop

Displays 3 images per row.

Tablet

Displays 2 images per row.

Mobile

Displays 1 image per row.
